# kino studio

Downloads for **kino studio**, the editor where your next developer already knows the codebase.

Get the latest version from [Releases](../../releases/latest) or from the website: https://kino-site-tau.vercel.app

This repository only holds the installers. The builds are not signed yet:
- **macOS:** the first time, right-click the app and choose Open.
- **Windows:** in the SmartScreen dialog choose More info, then Run anyway.

Check a download against `SHA256SUMS` in the release: `shasum -a 256 -c SHA256SUMS`.
